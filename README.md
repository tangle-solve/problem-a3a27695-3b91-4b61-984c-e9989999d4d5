### ALGO-000232: Log-rank conjecture
- **Subfield:** Communication complexity and adaptive data structures
- **Open:** Prove that deterministic two-party communication complexity is bounded by a polynomial in the logarithm of the real rank of the communication matrix.
- **Status:** Open since the late 1970s–1980s. Bounds depending approximately on the square root of rank remain far from polynomial dependence on log-rank; new equivalent formulations appeared in 2025–2026.
- **Type:** theory
- **Why:** Would connect algebraic simplicity to efficient distributed communication.
- **Key works:** Lovász and Saks (1988); Hambardzumyan, Lovett, and Shirley, *The Log-Rank Conjecture: New Equivalent Formulations*, arXiv:2510.02583, DOI: 10.4230/LIPIcs.CCC.2026.7.
- **Related:** Linear algebra—low-rank Boolean matrices.
